
# 🚖 Cab Booking System  
A full‑stack web application for seamless cab reservations, built using **ASP.NET Core**, **Entity Framework Core**, and **Microsoft SQL Server (MSSQL)**.  
The system allows users to book rides, view ride history, and enables admins to manage drivers, bookings, and user records.
